# Paint-by-Numbers Learning Resources and Project Checklist

Maintained by **DIY Art Muse**, a paint-by-numbers kit seller. This resource was drafted with AI assistance. Our own guides are labeled below. Inclusion of another organization does not mean it endorses DIY Art Muse.

Use this collection to choose a photo, compare a kit's practical requirements and plan a painting session. It is a reading list and worksheet, not a kit ranking or a report of hands-on product testing.

## Start with a task

The PBNify repository and the current pbnify.com website are separate things to assess. This list does not claim that the site's current service runs the repository's code or shares its license. No photo upload is required to use this checklist.

## Use the worksheet

Open [CHECKLIST.md](CHECKLIST.md), copy it into a note, or print it. Fill in the project fields before comparing sellers. Mark unresolved items as **unknown**, then take those questions to the seller. A blank answer is more useful than an assumed feature.

The worksheet works without following any store link. It asks what matters about your image, how the canvas will fit your workspace and which details you still need to confirm.

## How this list is curated

Resources are included for a specific learning task, a clear publisher and publicly readable material. External sources include a museum, a developer and manufacturers' documentation. A manufacturer explaining its own technology is a primary source, not an independent product reviewer.

Links and descriptions were checked on November 10, 2026. Availability and content can change. If suggesting a correction, include the resource URL, the task it helps with, the publisher and any commercial relationship. Do not submit personal photos or order details in public issues.
